# antislop audit 001 (2026-10-28)

Mode: after (session override). Target: `docs/design/preview/mockup-v2.html` on branch `zcode`, the static port of the landing design.
Skills applied: antislop core, antislop-ui, antislop-layoutmobile, antislop-human, antislop-copywriting.
Method: read the source, rendered it in Chromium at 1440/1280/900/768/390 px, measured contrast with `contrast-check.py`, counted elements by script. Nothing was changed.

Direction (R-37): no `DESIGN.md` exists. The design file supplied by the owner acts as the direction, so most visual choices below are marked "owner decision" when they come straight from it. Nothing here was invented in the port; the findings describe the design as delivered.

Priority follows tier: Hard Gate = HIGH, Purpose-Gate = MEDIUM, Quality Locks = LOW.

## HIGH (Hard Gate)

1. **Mobile hero overflows and clips (R-03).** At 390 px the hero column is 594 px wide inside a 326 px grid, so the H1, the install box and the COPY button are cut off on the right (measured: h1 right edge 626 px, viewport 390 px). Cause: `grid-template-columns:1fr` resolves to `minmax(auto,1fr)` and the `nowrap` install command forces the min-content width. The same CSS is in the original design file. Fix: `minmax(0,1fr)` plus `min-width:0` on the grid children.
2. **Em dash in UI text (R-02).** 8 occurrences: section labels `// 01 — HOW IT WORKS` to `// 04 — HARNESS & MCP`, the terminal title `~ — zsh`, the footer `rewire — portable synaptic memory`, and the page `<title>`. Fix: replace with a period, colon or comma (for example `// 01 · HOW IT WORKS`, which is a separator, not punctuation).
3. **Low contrast text (R-25).** `#6a63a8` is used for the section labels, `COMPATIBLE`, the terminal prompt `$`, comments in the code blocks, the footer text and small captions. Ratio is 3.80:1 on the page background and 3.69:1 on the card background, below 4.5:1 for normal text. Fix: raise it to at least `#8a84c8` (5.96:1), which is already in the palette.
4. **Window dots and borders (non-text contrast).** The three terminal dots `#3a3566` are 1.75:1 against the card. They are decorative, so this is LOW in practice, but it is the same color family as the failing text. Fix together with item 3 or remove the dots (see item 9).
5. **Harness support claims not backed by the repo (R-36, R-38).** The landing lists Gemini CLI, OpenCode, Hermes, OpenHuman, ZCode and Obsidian as compatible or supported. In the code, only `claude-code` and `codex` have an installer (`rust/src/cli.rs:105`, `integrations.rs:228,266`). `gemini`, `opencode` and `zcode` appear nowhere in `rust/src` or the README; Hermes and OpenHuman appear only in research notes. The README supports "any MCP client" and AGENTS.md. Fix, owner to choose: label the others "via MCP / AGENTS.md", or list only what is tested.
6. **Sample output is invented (R-38).** The terminal shows `✓ ~/brain created (git repo)`, `✓ hooks installed`, `✓ 3 claims proposed`, `healthy`. These are illustrative, not real captured output, and are not labelled as such. Fix: paste real output of those commands, or add a visible "example" label.
7. **Under-sized tap targets on mobile (R-03).** Nav links are 17 px tall, the COPY button 57 x 32 px, the "Star on GitHub" link 33 px. Minimum is 44 x 44 px. Fix: padding on the nav links and the COPY button at the mobile breakpoint.
8. **Endless motion with no reduced-motion handling (R-19, R-32 family, WCAG 2.2.2).** 4 CSS animations run forever (cursor blink, `healthy` fade, two marquees) plus 8 `animateMotion` dots. Only the canvas checks `prefers-reduced-motion`. Fix: a `@media (prefers-reduced-motion: reduce)` block that stops the CSS animations and the SVG dots, and a pause control or static fallback for the marquees.

## MEDIUM (Purpose-Gate: allowed, reason not written down)

9. **Fake terminal windows (R-05, antislop-ui).** The connect section and both format panels use window chrome (three dots, title bar). The commands are real for a CLI product, so the content is justified, but the traffic-light costume is the default. Fix: keep the code blocks, drop the three dots, or state the reason.
10. **Default AI palette and gradients (R-01).** Blue-purple-cream gradient on the H1 and on both buttons, purple-on-near-black base, radial glow behind the hero. Dark is legitimate for a developer tool (R-21), but the gradient needs a written purpose. Owner decision; record the reason in a `DESIGN.md`.
11. **Glass on four cards (R-10).** `backdrop-filter` on the four step cards in the connect section. Dose cap is 1 to 2 elements. Fix: keep it on one card or none.
12. **Glow and shadow stacking (R-12, R-13).** Glow on the REWIRE node, drop shadows on every terminal and step card, glow on the final CTA and bright dots in the canvas. Fix: keep glow on one element.
13. **Eyebrow labels in tracked uppercase mono (R-06).** `// 01 — HOW IT WORKS` and the like, and `COMPATIBLE`, `$ rewire doctor`. Mono with wide tracking is on the Generic AI Typography list. Fix: write the reason (a CLI product has a legitimate mono voice) or set them in the body face.
14. **Decorative status text (antislop-ui, Decorative Status Dot).** `$ rewire doctor · healthy` above the H1 is an eyebrow that pulses forever and marks no real state. Fix: remove it, or tie it to something real.
15. **Duplicate logo strips.** The hero "COMPATIBLE" strip and the section 04 strip show the same logos twice, both as endless marquees. Fix: keep one.
16. **Copy-paste step cards (R-14).** The four connect cards have identical size, padding and layout, and repeat what the terminal beside them already says. Fix: merge the steps into the terminal comments, or vary the cards.
17. **Section rhythm is uniform (R-05).** Every section is the same shape: numbered mono label, H2 with a purple second half, paragraph, content block. The declared dial is not recorded; it reads as ENERGY 2 / RHYTHM 1 / MOTION 3 and the marquees push motion higher than the layout suggests. Fix: write the dials, or vary one or two sections.
18. **Arrow on the main CTA (R-08).** `Star on GitHub →`. Minor; write the purpose or drop it.

## LOW (Quality Locks and hygiene)

19. **Section 05 is generic filler (R-15, R-16).** "Give it a test." plus "Four commands. One private git repo. No server, no vendor." and a second "Star on GitHub" button duplicating the nav one. Fix: replace with the actual next step (install command or docs link).
20. **No `<main>` landmark and no skip link (R-32).** The page has `nav`, `header`, `section`, `footer` but no `main`. Fix: wrap the sections in `<main>`.
21. **Marquee text duplicated for screen readers.** The section 04 strip repeats every label twice and only the hero strip marks its copy `aria-hidden`. Fix: `aria-hidden` on the second copy.
22. **External icons from CDNs.** Logos load from `cdn.simpleicons.org` and jsDelivr `@latest`. If a CDN is down or blocked the strip shows broken images. Fix: vendor the SVGs into `assets/` and pin versions.
23. **Font loaded from Google Fonts only.** No local fallback metrics, so layout can shift when Geist loads. Minor.
24. **Sentence patterns (copywriting).** "Own the brain. Plug it into any agent." is fine. Watch the staccato "Four commands. One private git repo. No server, no vendor." (staccato drama, one instance) and "Memory flows back to every agent" (inanimate subject with a human verb). Low priority.

## Passed
- No fake statistics, testimonials, logos of customers, or FAQ (R-17, R-18, R-28).
- Navigation links all point to existing sections; all buttons have behavior now (COPY copies the command) (R-24, R-26).
- No `outline:none`, so default focus rings remain (R-32).
- No horizontal page scroll at any tested width.
- Claims on the page that I checked against the repo are true: single Rust binary, bundled SQLite, ACT-R-style activation, secrets rejected on the way in, hooks for Claude Code, no LLM call in the recall path.

## Not checked
- Pixel diff against the original design (only visual comparison was done).
- Keyboard walk-through with a real screen reader.
- The canvas animation's frame cost on low-end phones.
