// 01 — HOW IT WORKS

Transcripts in. Memory out.

Sessions are distilled into atomic claims and committed to a git repo you own. Each claim has an ACT-R-style activation: every use is logged, and recent uses weigh more than old ones. Recall searches a local SQLite index and ranks results by that activation, so the strongest claims are read back first.

Memory flows back to every agent
Before the next session, Rewire primes only what matters as a fenced <rewire-memory> block, in any harness.

Every session is captured: Claude Code hooks queue the transcript on PreCompact (before context is lost) and SessionEnd, and consolidation runs in the background so the agent never waits. Read: prime at SessionStart, then recall on demand. Other harnesses use AGENTS.md or MCP. Secrets are rejected on the way in.

// 02 — CONNECT

Connect in 4 steps.

Install once, attach your harness, and every session is captured in the background. You only approve what Rewire proposes.

~ — zsh
# 1 · install
$cargo install --git github.com/NewbeeTryToCode/rewire rewire
# 2 · create the brain
$rewire init
✓ ~/brain created (git repo)
# 3 · attach your harness
$rewire install claude-code --write
✓ hooks installed
# 4 · work as usual, then approve
$rewire review
✓ 3 claims proposed

// 03 — THE BRAIN, ON DISK

Just files. Readable, diffable, yours.

Every memory is a markdown note with frontmatter, linked by wikilinks. Usage is an append-only log. The index is derived and can be rebuilt any time.
