// 01 — HOW IT WORKS

Transcripts in. Memory out.

// 02 — CONNECT

Connect in 4 steps.

[ 01 ]

Install

One Rust binary. SQLite bundled, no runtime.

sh
$ cargo install --git github.com/NewbeeTryToCode/rewire rewire
[ 02 ]

Create the brain

A private git repo of markdown — yours, portable, diffable.

sh
$ rewire init
[ 03 ]

Attach your harness

Hooks for Claude Code. MCP or AGENTS.md snippet for the rest.

sh
$ rewire install claude-code --write
[ 04 ]

Work as usual

Sessions consolidate in the background. Arm the honeypot for proof:

sh
$ rewire canary # optional
