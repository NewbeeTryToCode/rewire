K — SINAPSIS + BRAIN

K1 · BRIDGE
Dua neuron, satu nyala
Dua neuron kosong (agent + brain) dihubungkan satu sinapsis kecil. Tiga bentuk, satu ide.
K2 · HEMISPHERE
Dua lobus, sinapsis tengah
Otak dua hemisfer sederhana; satu dot kuning di tengah fisur.
K3 · SPROUT
Dua tunas menghadap
Dua kabel menancap dari bawah, ujungnya tumbuh jadi dendrit; pulse di pusat.
K4 · CONSTEL
Otak konstelasi dot
Titik-titik membentuk siluet otak; satu edge kuning menyala = klaim aktif.

P — PIN

P1 · SOCKET
Pin masuk soket
Satu pin menancap ke node bulat � "plug into your brain". Paling simpel.
P2 · CONNECTOR
Terminal 3-pin + housing
Tiga pin ke male-connector, ujungnya dot kuning. Nyaris seperti header pin di PCB devboard.
P3 · LOLLi
Pin dengan ring kepala + gosong
Lollipop pin: ring kepala, kaki pendek, dot kuning. Aman diukur sangat kecil.
P4 · MERGE
Dua kabel menyatu ke pin
Dua kabel dari kiri-kanan menyatu ke satu solder point: "semua harness telepas ke satu repo".
